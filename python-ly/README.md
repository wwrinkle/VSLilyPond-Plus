# Bundled python-ly

Unmodified copy of [python-ly](https://github.com/frescobaldi/python-ly) 0.9.7
(the `ly` package from the PyPI source release), by Wilbert Berendsen and contributors.

python-ly is licensed under the GNU General Public License, version 2 or (at your
option) any later version; see `COPYING`. Source: https://pypi.org/project/python-ly/0.9.7/

VSLilyPond Plus runs it as a separate process (`python3 -m ly reformat`) to format
files on save.
